# Santa Cruz Mountain Photography — Coming Soon

A single-page "coming soon" splash for Santa Cruz Mountain Photography.

## Structure

- `index.html` — page markup
- `style.css` — styling
- `images/hero.jpg` — full-bleed background photo

## Local preview

Serve the folder with any static file server, e.g.:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploying

This is a fully static site — no build step. It can be deployed as-is to
Netlify, Vercel, GitHub Pages, or any static host by pointing it at this
folder.
